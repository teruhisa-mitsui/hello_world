# 質問応答AIエージェント

## 概要
このプロジェクトは、事前に読み込ませた資料に基づいて質問に回答するAIエージェントです。
ISMSの規定に合致するよう、外部との通信を行わないローカル環境での動作を前提として設計されています。

## 特徴
- 📚 複数の文書形式（PDF、Word、テキスト等）の読み込み対応
- 🔒 完全にローカル環境での動作（外部通信なし）
- 🛡️ ISMSの規定に準拠したセキュリティ設計
- 🎯 根拠となる資料箇所の提示機能
- 📊 質問履歴の管理・分析機能

## 技術スタック
- **バックエンド**: Python 3.9+, FastAPI
- **フロントエンド**: React
- **AI/ML**: Hugging Face Transformers (ローカル実行)
- **データベース**: SQLite
- **ベクトル検索**: FAISS
- **文書処理**: PyPDF2, python-docx, OpenPyXL

- ISMS（情報セキュリティマネジメントシステム）の規定に準拠
